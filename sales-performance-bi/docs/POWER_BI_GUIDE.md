# Power BI report guide

Run the analysis once from the repository root:

```bash
python sales-performance-bi/scripts/run_analysis.py
```

Use Power BI Desktop to create the report. The `.pbix` file is created locally and is not generated by this repository.

## 1. Load the data

1. Open Power BI Desktop.
2. Select **Get data → Text/CSV**.
3. Load `sales-performance-bi/outputs/sales_enriched.csv`.
4. Confirm `order_date` is Date, numeric fields are Decimal Number or Whole Number, and `discount_pct` / `profit_margin` are Decimal Number.
5. Name the table `Sales`.

## 2. Create measures

```dax
Net Revenue = SUM(Sales[revenue])

Total Profit = SUM(Sales[profit])

Orders = DISTINCTCOUNT(Sales[order_id])

Units Sold = SUM(Sales[quantity])

Profit Margin = DIVIDE([Total Profit], [Net Revenue])

Average Order Value = DIVIDE([Net Revenue], [Orders])

Discounted Sales = CALCULATE([Net Revenue], Sales[discount_pct] > 0)
```

Format Net Revenue, Total Profit and Average Order Value as currency; format Profit Margin as a percentage. The sample uses generic monetary values rather than a declared real-world currency.

## 3. Suggested report layout

- Top KPI cards: Net Revenue, Total Profit, Profit Margin and Orders.
- Line chart: month versus Net Revenue.
- Bar chart: region by Total Profit.
- Bar chart: product category by Net Revenue.
- Matrix: product and category with Units Sold, Net Revenue, Total Profit and Profit Margin.
- Slicers: region, category, channel, customer segment and order date.

## 4. Questions the report should answer

- Is revenue increasing or decreasing over the available months?
- Which region produces the most profit, not just revenue?
- Which categories have strong sales but weak margins?
- How does discounting vary across channels and segments?
- Do conclusions change when a region or category is selected?

## 5. Finish the report

Use descriptive chart titles, consistent number formatting, readable labels and meaningful alt text. Add a footer noting that the dataset is synthetic. Save the file locally if desired; do not upload a large report unless it adds value and contains no restricted data.

## Interpretation note

The dataset is synthetic and does not represent a real company. Any patterns shown are only examples of how to build and explain a business intelligence report.
