# Data

`raw/sales.csv` contains synthetic retail order lines created for this portfolio project. Each row is one order line, and each order ID is unique in this sample.

- 120 records
- Dates span 2025–2026
- No real customer information
- Prices and costs are illustrative, in unspecified monetary units
- `discount_pct` is stored as a decimal from 0 to 1 (for example, 0.10 means 10%)

Do not describe the data as company data or use it to make real business claims. The analysis script derives revenue, cost, profit and margin.
